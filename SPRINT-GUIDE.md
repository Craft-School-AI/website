# Гайд по спринтам Craft School — сценарий для мастера

Это **рабочий сценарий занятий**: по нему ты ведёшь поток от пустого компьютера
ученика до сайта на его собственном домене, который принимает заявки.

Гайд — спутник [PROGRAM.md](PROGRAM.md) (там расписание и тайминги). Здесь —
конкретные шаги, команды и **готовые промпты**, которые можно давать ученику
как есть.

## Как пользоваться

- **Формат каждого шага:** показал сам → ученик повторяет → разобрали затык.
- **Промпты в рамках** — копируются ученику дословно. Ученик подставляет своё
  (название бизнеса, услуги) в квадратных скобках `[...]`.
- **Чекпоинт** в конце шага — что должно получиться. Не двигаемся дальше, пока
  у ученика не тот же результат.
- **⚠️ Частые затыки** — то, на что реально наступают. Держи под рукой.
- Занятия по 1 часу — живое время это чекпоинты и разбор; основную сборку
  ученик делает между занятиями (домашка).

> **Перед первым потоком пройди весь гайд сам как ученик** — с чистой машины,
> новым GitHub-аккаунтом и тестовым доменом. Чек-лист самопроверки — в конце.

---

## Что мастер готовит ДО старта потока

- [ ] **Открыть самозанятость** (через «Мой налог», ~1 день) — чтобы легально
      принимать оплату за курс.
- [ ] **API-токен на каждого ученика с лимитом.** В консоли Anthropic заводишь
      отдельное рабочее пространство (workspace) на ученика и ставишь месячный
      лимит трат: $50 / $100 / $200 по тарифу. Ключ из этого workspace выдаёшь
      ученику — больше лимита он не потратит.
- [ ] **VPN-доступ.** Агент обращается к API Anthropic, а он из РФ недоступен
      напрямую — нужен VPN. Подготовь рабочий вариант и короткую инструкцию.
- [ ] **Ссылки на установщики** (см. Занятие 1) и шаблон промпта-брифа.
- [ ] **Тестовый прогон** этого гайда целиком.

# СПРИНТ 1 — Знакомство с ИИ-станком

## Занятие 1. Рабочее место мастера

**Цель:** у ученика настроено окружение и агент отвечает на команды.
**Чекпоинт занятия:** агент создал первый файл на компьютере ученика и запушил
его в репозиторий на GitHub.

### Шаг 1.1. VPN
Включаем VPN и проверяем, что открывается `anthropic.com`. Без VPN агент не
подключится к API — это первый и главный затык, проверь его сразу.

### Шаг 1.2. Устанавливаем инструменты (по порядку)
1. **VS Code** — [code.visualstudio.com](https://code.visualstudio.com/) — редактор, «верстак».
2. **Git** — [git-scm.com/downloads](https://git-scm.com/downloads) — история изменений.
3. **Node.js LTS** — [nodejs.org](https://nodejs.org/) — среда, где живут сайты.
4. Аккаунт на **[github.com](https://github.com)** — облако для кода.
5. **ИИ-агент** (Claude Code) — устанавливаем и авторизуем по твоей инструкции.

### Шаг 1.3. Проверяем установку — первый промпт
Открываем терминал в VS Code (`Terminal → New Terminal`) и запускаем агента.
Даём ученику первый промпт:

```
Проверь, что у меня установлены git и node — покажи их версии.
Если чего-то нет, объясни простыми словами, что скачать и куда нажать.
```

### Шаг 1.4. Первый файл и первый репозиторий

```
Создай папку для проекта моего сайта, инициализируй в ней git-репозиторий
и создай файл README.md, где в двух-трёх предложениях опиши мой бизнес:
[расскажите про свой бизнес: чем занимаетесь, кто ваши клиенты].
Затем помоги мне создать пустой репозиторий на GitHub и запушить туда файл.
```

**Чекпоинт:** файл `README.md` виден в репозитории ученика на GitHub.

**⚠️ Частые затыки занятия 1:**
- *Агент не отвечает / ошибка сети* → не включён VPN (шаг 1.1).
- *`node`/`git` «не является командой»* → не установлен или не перезапущен
  терминал после установки. Закрыть и открыть терминал заново.
- *Git просит имя и email при первом коммите* → попроси агента: «настрой мне
  git — имя и email», подставит `git config`.
- *Просит логин/пароль при пуше* → нужен вход в GitHub через браузер (агент
  проведёт) либо токен доступа.

**Домашка:** задать агенту 5 своих вопросов про будущий сайт, принести самый
интересный ответ.

## Занятие 2. Рождение сайта

**Цель:** сформулировать задание и получить первую версию сайта.
**Чекпоинт занятия:** сайт открывается в браузере на компьютере ученика.

### Шаг 2.1. Готовим бриф (25 минут)
Разбираем вслух: кто клиент, что продаём, какое действие ждём от посетителя,
какое настроение. Главный навык — **описать бизнес словами**, технологии
назовёт агент.

### Шаг 2.2. Большой промпт-задание
Даём шаблон, ученик заполняет `[...]` своим:

```
Ты — senior fullstack-разработчик на Next.js и Tailwind CSS + TypeScript.
Разработай лендинг для моего бизнеса «[название]».

О бизнесе: [кто вы, что продаёте, кто ваши клиенты].

Тональность и стиль: [тёплый / строгий / яркий], основные цвета:
[например, терракотовый, золотой, слоновая кость]. Поддержка тёмной
и светлой темы.

Структура: Главная, Услуги и цены, Обо мне, Отзывы, Контакты.
На главной: продающий заголовок, 3 преимущества, блок «для кого»,
блок «как это работает», отзывы, форма заявки.

Требования: адаптив под телефоны, SEO-метаданные, лёгкие анимации.
Тексты — коротко и без жаргона, моя аудитория далека от IT.
Заведи проект и покажи, как запустить его у меня на компьютере.
```

### Шаг 2.3. Запускаем локально

```
Запусти сайт у меня на компьютере и дай ссылку, которую я открою в браузере.
```

Агент выполнит `npm run dev` и даст адрес вида `http://localhost:3000`.

**Чекпоинт:** сайт открывается в браузере, видна первая версия.

**Приёмы, которым учим здесь:**
- Просить объяснения: «Расскажи, что ты сделал, как для человека без
  технического образования».
- Смотреть результат в браузере **после каждого шага**, не в конце.
- Не нравится — говорить словами: «Заголовок слишком агрессивный, сделай
  спокойнее и теплее».

**⚠️ Частые затыки занятия 2:**
- *Порт 3000 занят* → попроси агента запустить на другом порту, он подставит.
- *Долго ставятся зависимости* → это нормально в первый раз (`npm install`).
- *Белый экран / ошибка* → скопируй текст ошибки агенту: «вот ошибка, почини».

**Домашка:** выписать все настоящие тексты сайта (заголовки, услуги, цены)
в отдельный файл.

# СПРИНТ 2 — Сайт целиком

## Занятие 3. Тексты, стиль, темы

**Цель:** заготовка превращается в сайт с характером ученика.
**Чекпоинт:** все страницы с настоящими текстами, палитра и шрифты — свои,
работают обе темы.

### Промпты занятия

Настоящие тексты:
```
Замени тексты-заглушки на мои настоящие: [вставьте свои тексты].
Сохрани стиль: коротко, по делу, без воды.
```

Цвета через дизайн-токены (чтобы менять в одном месте):
```
Давай поиграемся с цветами. Моя палитра: фон [цвет], карточки [цвет],
главный акцент [цвет]. Сделай так, чтобы цвета задавались в одном месте
и работали и в светлой, и в тёмной теме.
```

Шрифт:
```
Мне не нравится шрифт, он неудобно читается. Подбери что-то тёплое
и хорошо читаемое, с поддержкой кириллицы.
```

Мобильная версия:
```
Проверь, как сайт выглядит на телефоне, и исправь всё, что съезжает
или мелко читается.
```

**⚠️ Затык:** ученик меняет текст «руками» в коде и ломает разметку → напомни:
все правки — через агента, словами.

**Домашка:** подготовить 3–5 фотографий (себя за работой, товары/результаты,
рабочее место).

## Занятие 4. Дороговизна: фото, иконки, логотип, wow

**Цель:** убрать «дешёвый шаблонный» вид.
**Чекпоинт:** сайт выглядит сделанным на заказ, а не собранным на конструкторе.

Разбор с группой — **4 признака «дешёвого» сайта:** эмодзи вместо иконок, ни
одной фотографии, всё по центру одинаковыми карточками, отзывы без лиц.

### Промпты занятия

```
Сайт получился слишком «дешёвым». Что мне прислать и что сделать,
чтобы он выглядел дороже и не таким шаблонным?
```
```
Вот моё фото для первого экрана. Встрой его красиво и асимметрично,
как в дорогом журнальном лендинге.
```
```
Замени все эмодзи на аккуратные иконки в едином стиле
(например, с lucide.dev).
```
```
Сделай мне простой логотип и favicon, поставь их в шапку, подвал
и на вкладку браузера.
```
```
Добавь лёгкие анимации появления при прокрутке и плавный скролл —
так, чтобы это не замедлило сайт и не ухудшило SEO.
```
```
Сделай красивую картинку-превью (Open Graph), чтобы при отправке ссылки
в мессенджер показывалась обложка, а не пустой прямоугольник.
```

**Домашка:** показать сайт трём знакомым с телефона, записать, что было
непонятно — это список правок на следующее занятие.

# СПРИНТ 3 — Запуск и заявки

## Занятие 5. Форма заявок и уведомления

**Цель:** сайт начинает приносить пользу — принимает заявки.
**Чекпоинт:** ученик заполняет форму → заявка приходит ему в мессенджер.

### Важный момент про доставку заявок

Куда слать заявку, зависит от того, где будет жить сайт:

- **Хостинг в России (Timeweb)** → Telegram оттуда **заблокирован**
  (`api.telegram.org` недоступен). Используем **ВКонтакте**: заявка уходит
  через API сообщества.
- **Vercel (зарубежный)** → Telegram работает нормально.

Реши это заранее по тарифу ученика. Ниже — путь для ВКонтакте (для Timeweb).

### Шаг 5.1. Готовим ВКонтакте
1. Создать (или взять) **сообщество** ВКонтакте.
2. Управление → Настройки → **Работа с API** → создать **ключ доступа**
   с правом «Управление сообщениями сообщества».
3. Узнать свой числовой **VK id** (vk.com/settings) — туда будут падать заявки.

### Шаг 5.2. Подключаем форму

```
Сделай так, чтобы заявка с формы прилетала мне в личку ВКонтакте.
Ключ доступа сообщества и мой VK id я положу в переменные окружения —
подскажи, как их называть и куда вписать.
```

Агент заведёт форму с проверкой полей и серверный обработчик. Токены хранятся
в файле `.env.local`, который **не попадает в git**.

### Шаг 5.3. Тестируем и сохраняем

```
Отправь тестовую заявку через форму и проверь, что она дошла.
Если что-то не так — разберись и почини.
```
```
Давай сохраним и запушим текущий результат на GitHub.
```

**⚠️ Частые затыки занятия 5:**
- *Форма отвечает «временно недоступна» (503)* → не заданы или неверны ключ/ID
  в переменных окружения.
- *Хочется Telegram, но сайт на Timeweb* → не заработает из РФ, объясни про
  блокировку, веди на VK.

**Домашка:** отправить себе 3 тестовых заявки с разных устройств.

## Занятие 6. Запуск в интернет — Timeweb + свой домен

**Цель:** сайт доступен всему миру по настоящему адресу.
**Чекпоинт:** ссылка на сайт ученика на его домене, форма работает на проде.

Есть два пути — выбираем по тарифу:

### Путь А (просто) — Vercel, рабочая ссылка
Для базового тарифа: быстрый бесплатный деплой, ссылка вида `имя.vercel.app`.
```
Давай задеплоим сайт на Vercel и получим рабочую ссылку.
Проведи меня по шагам.
```
> Нюанс: бесплатный Vercel не подключает репозитории из GitHub-организаций —
> репозиторий должен лежать на личном аккаунте ученика.

### Путь Б (полный) — Timeweb + свой домен
Для среднего и высшего тарифа: настоящий хостинг в России и свой домен.

**Шаг 6.1. Покупаем домен** (reg.ru или сам Timeweb).

**Шаг 6.2. Разворачиваем на Timeweb.**
Важно: наш сайт — это Node.js-приложение (форма и аналитика требуют сервер),
поэтому нужен тариф с **Node.js**, а не простой «хостинг сайтов».
```
Помоги развернуть мой сайт на Timeweb (тариф с Node.js).
Объясни по шагам: как подключить мой GitHub-репозиторий, какие указать
команды сборки и запуска, и какие переменные окружения прописать.
```
Ключевое, что агент настроит:
- Команда сборки: `npm run build`, команда запуска: `npm run start`.
- Порт берётся из переменной `PORT` (Timeweb задаёт сам).
- **Переменные окружения** на хостинге: ключ и ID ВКонтакте, публичный адрес
  сайта, ID Яндекс.Метрики.

**Шаг 6.3. Привязываем домен.** В панели Timeweb добавляем домен и прописываем
у регистратора DNS-записи, которые покажет Timeweb. Ждём обновления DNS и
включения HTTPS.
```
Помоги привязать мой домен к сайту на Timeweb и включить HTTPS.
```

**Шаг 6.4. Проверяем прод.**
```
Проверь, что сайт открывается по моему домену, форма отправляет заявку,
и всё работает на телефоне. Если что-то не так — почини.
```

### Документы, аналитика, cookie (в этом же спринте)
```
Составь для моего сайта политику конфиденциальности и публичную оферту
под мои данные: [ФИО / статус самозанятого / ИНН / контакты].
```
```
Подключи Яндекс.Метрику и баннер согласия на cookie — так, чтобы аналитика
включалась только после согласия посетителя.
```

**⚠️ Частые затыки занятия 6:**
- *Сборка падает с ошибкой про `sharp`* → нужна установка пакета оптимизации
  картинок; попроси агента: «поставь sharp и пересобери».
- *Форма молчит на проде* → не заданы переменные окружения на хостинге (частая
  ошибка — заданы локально, но забыли на сервере).
- *Домен не открывается сразу* → DNS обновляется до нескольких часов, это норма.
- *Заявки перестали ходить после переезда на Timeweb* → был Telegram, а из РФ
  он заблокирован; переключаем на ВКонтакте (Занятие 5).

**Выпускной чек-лист ученика:**
- [ ] Сайт открывается по своему домену (или ссылке vercel.app)
- [ ] Заявка с боевого сайта приходит в мессенджер
- [ ] На телефоне всё читается, кнопки нажимаются
- [ ] При отправке ссылки в мессенджер видно превью (обложка)
- [ ] Код на GitHub, ученик умеет делать коммит и пуш

# Чек-лист самопроверки мастера

Пройди это сам **с чистой машины**, как будто ты ученик. Если на каком-то шаге
замялся или полез в код руками — значит, в этом месте замнётся и ученик,
допиши туда пояснение.

1. [ ] Включил VPN, открыл anthropic.com.
2. [ ] Поставил VS Code, Git, Node, завёл GitHub — только по ссылкам из гайда.
3. [ ] Авторизовал агента, дал ему первый промпт — он ответил и создал файл.
4. [ ] Запушил README в новый репозиторий.
5. [ ] Собрал сайт по большому промпту-брифу, открыл в браузере.
6. [ ] Залил свои тексты, поменял цвета и шрифт, проверил обе темы и телефон.
7. [ ] Встроил фото, иконки, логотип, favicon, OG-превью.
8. [ ] Подключил форму → заявка пришла в VK (или Telegram на Vercel).
9. [ ] Развернул на Timeweb, привязал домен, включил HTTPS.
10. [ ] Прописал переменные окружения на хостинге, проверил форму на проде.
11. [ ] Сгенерировал политику и оферту, подключил Метрику и cookie-баннер.

Каждый пункт, где пришлось гуглить или звать на помощь, — это место для нового
«⚠️ затыка» в гайде.

# Сводка частых проблем

| Симптом | Причина | Решение |
| --- | --- | --- |
| Агент не отвечает, ошибка сети | Нет VPN | Включить VPN, проверить anthropic.com |
| `node`/`git` — не команда | Не установлен / не перезапущен терминал | Переоткрыть терминал |
| Просит логин при пуше | Нет входа в GitHub | Войти через браузер или токеном |
| Порт 3000 занят | Другой процесс | «Запусти на другом порту» |
| Белый экран / ошибка | Баг в сборке | Скопировать текст ошибки агенту |
| Форма: 503 «недоступна» | Нет ключей в env | Задать VK-ключ и ID на хостинге |
| Заявки не ходят с Timeweb | Telegram блокирован в РФ | Перейти на ВКонтакте |
| Сборка падает про sharp | Нет пакета | «Поставь sharp и пересобери» |
| Домен не открывается | DNS ещё обновляется | Подождать до нескольких часов |
