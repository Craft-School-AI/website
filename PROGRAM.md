# Программа Craft School

**Формат:** 3 недели · 2 занятия в неделю · 90 минут занятие · 6 занятий всего.

**Результат программы:** работающий сайт вашего бизнеса в интернете — с формой заявок,
которые прилетают вам в Telegram. Сделанный вашими руками с помощью ИИ-агента.

**Принцип:** вы не учитесь программировать. Вы учитесь ставить задачи ИИ-агенту,
проверять его работу и принимать результат — как мастер за станком.

> Эта программа собрана из реальных шагов разработки сайта craft-school.ru.
> Каждый промпт из примеров был использован в бою.

---

## Неделя 1 — Спринт «Знакомство с ИИ-станком»

### Занятие 1. Рабочее место мастера

**Цель:** настроить окружение и впервые поговорить с агентом.
**Результат занятия:** агент отвечает на команды и создал первый файл на вашем компьютере.

| Время | Блок |
| --- | --- |
| 0:00–0:30 | Установка инструментов: VS Code, Git, Node.js. Регистрация на GitHub |
| 0:30–1:00 | Установка и подключение ИИ-агента (Claude Code). Первый диалог |
| 1:00–1:30 | Практика: агент создаёт папку проекта, git-репозиторий, файл о вашем бизнесе |

**Что ставим (по порядку):**
1. [VS Code](https://code.visualstudio.com/) — редактор, наш «верстак».
2. [Git](https://git-scm.com/downloads) — сохраняет историю изменений (машина времени для проекта).
3. [Node.js LTS](https://nodejs.org/) — среда, в которой живут современные сайты.
4. Аккаунт на [github.com](https://github.com) — облако для кода.
5. ИИ-агент — устанавливаем и авторизуем по инструкции мастера.

**Примеры промптов:**

```
Проверь, что у меня установлены git и node. Покажи их версии
и объясни простыми словами, что делает каждый из них.
```

```
Создай папку для проекта моего сайта, инициализируй в ней git-репозиторий
и создай файл README.md, где коротко опиши мой бизнес: [расскажите про свой
бизнес двумя-тремя предложениями].
```

**Домашнее задание:** написать агенту 5 любых вопросов о вашем будущем сайте
и принести самый интересный ответ на следующее занятие.

---

### Занятие 2. Рождение сайта

**Цель:** сформулировать задание на сайт и получить первую работающую версию.
**Результат занятия:** сайт открывается в браузере на вашем компьютере.

| Время | Блок |
| --- | --- |
| 0:00–0:25 | Готовим бриф: кто клиент, что продаём, какое действие ждём от посетителя |
| 0:25–0:45 | Выбираем стилистику: цвета, настроение, 2–3 сайта-референса |
| 0:45–1:20 | Агент разворачивает проект (Next.js + Tailwind) по большому промпту-заданию |
| 1:20–1:30 | Запускаем сайт локально, осматриваем результат |

**Главный навык занятия — большой промпт-задание.** Хороший бриф агенту отвечает
на пять вопросов: кто вы, для кого сайт, какие страницы нужны, какое настроение
и какое целевое действие. Технологии называет мастер — вы описываете бизнес.

**Пример промпта (шаблон брифа):**

```
Ты — senior fullstack-разработчик на Next.js и Tailwind CSS + TypeScript.
Разработай лендинг для моего бизнеса «[название]».

О бизнесе: [кто вы, что продаёте, кто ваши клиенты].

Тональность и стиль: [тёплый/строгий/яркий], основные цвета: [например,
терракотовый #C67B5A, золотой #D4A54A, слоновая кость #FDF8F0].
Поддержка тёмной и светлой темы.

Структура страниц: Главная, Услуги и цены, Обо мне, Отзывы, Контакты.

На главной: продающий заголовок, 3 ключевых преимущества, блок «для кого»,
блок «как это работает», отзывы, форма заявки.

Требования: адаптив под телефоны, форма заявки с валидацией,
SEO-метаданные, лёгкие анимации. Тексты — коротко и без жаргона,
моя аудитория далека от IT.
```

**Приёмы проверки работы агента:**
- Просите объяснить: «Расскажи, что ты сделал, как для человека без технического образования».
- Смотрите результат в браузере после каждого крупного шага, а не в конце.
- Не нравится — говорите словами: «Заголовок слишком агрессивный, сделай спокойнее».

**Домашнее задание:** выписать все тексты сайта (заголовки, описания услуг, цены)
в отдельный файл — на следующем занятии зальём их на страницы.

## Неделя 2 — Спринт «Сайт целиком»

### Занятие 3. Страницы, тексты и фирменный стиль

**Цель:** превратить заготовку в полноценный сайт с вашим характером.
**Результат занятия:** все страницы наполнены вашими текстами, палитра и шрифты — ваши.

| Время | Блок |
| --- | --- |
| 0:00–0:30 | Заливаем настоящие тексты и цены на все страницы |
| 0:30–1:00 | Играем с цветами: настраиваем палитру через дизайн-токены |
| 1:00–1:30 | Подбираем шрифты, проверяем читаемость, тёмная/светлая тема |

**Примеры промптов:**

```
Замени тексты-заглушки на странице услуг на мои настоящие:
[вставьте свои тексты]. Сохрани стиль: коротко, по делу, без воды.
```

```
Давай поиграемся с цветами. Вот моя палитра:
основной фон [цвет], карточки [цвет], главный акцент [цвет].
Сделай так, чтобы цвета задавались в одном месте
и работали и в светлой, и в тёмной теме.
```

```
Мне не нравится шрифт, он неудобно читаемый.
Нужно что-то вроде Manrope, Arial, sans-serif.
```

**Домашнее задание:** сделать или подобрать 3–5 фотографий для сайта
(вы за работой, ваши товары/результаты, рабочее место).

---

### Занятие 4. Дороговизна: фото, иконки, логотип, анимация

**Цель:** убрать «дешёвый шаблонный» вид, добавить фирменные детали.
**Результат занятия:** сайт выглядит как сделанный на заказ, а не собранный на конструкторе.

| Время | Блок |
| --- | --- |
| 0:00–0:25 | Встраиваем фотографии (hero-блок, страница «Обо мне») |
| 0:25–0:50 | Меняем эмодзи на профессиональные иконки (Lucide) |
| 0:50–1:15 | Логотип: генерируем или встраиваем готовый, ставим в шапку и favicon |
| 1:15–1:30 | Плавный скролл и анимации появления — «дорогое» ощущение движения |

**Разбор с мастером: 4 признака «дешёвого» сайта** — эмодзи вместо иконок,
ни одной фотографии, всё по центру одинаковыми карточками, отзывы без лиц.
Проверяем каждый сайт группы по этому списку.

**Примеры промптов:**

```
Сайт получился слишком «дешёвым». Что мне нужно тебе предоставить,
чтобы он выглядел дороже и не таким массмаркетным?
```

```
Вот фото для header. Встрой его в первый экран красиво и асимметрично,
чтобы было похоже на дорогой журнальный лендинг.
```

```
Давай добавим иконки с https://lucide.dev/, чтобы не использовать эмодзи.
Замени все эмодзи на сайте на иконки в едином стиле.
```

```
Добавь плавный инерционный скролл (Locomotive Scroll),
но так, чтобы это не ухудшило SEO.
```

**Домашнее задание:** показать сайт трём знакомым с телефона и записать,
что им было непонятно. Это список правок на следующее занятие.

## Неделя 3 — Спринт «Запуск и заявки»

### Занятие 5. Форма заявок и Telegram-бот

**Цель:** сайт начинает приносить пользу — принимает заявки.
**Результат занятия:** заполняете форму на сайте — заявка приходит вам в Telegram.

| Время | Блок |
| --- | --- |
| 0:00–0:20 | Правки по итогам домашки (что было непонятно людям) |
| 0:20–0:45 | Создаём Telegram-бота через @BotFather, получаем токен |
| 0:45–1:15 | Агент подключает форму к боту, тестируем отправку |
| 1:15–1:30 | Сохраняем результат: коммит и пуш на GitHub |

**Важно знать (это сэкономит полчаса):**
- Токен бота — это пароль. Он живёт в файле `.env.local`, который никогда не попадает в git.
- Бот не может написать вам первым: после создания бота отправьте ему `/start`.
- Свой ID в Telegram узнаётся у бота @userinfobot.

**Примеры промптов:**

```
Сделай так, чтобы заявка с формы напрямую прилетала от бота мне в личку
в Telegram. Вот токен бота — я положил его в .env.local.
```

```
Отправь тестовую заявку через форму и проверь, что она дошла.
Если что-то не так — разберись и почини.
```

```
Давай сохраним и запушим текущий результат на GitHub.
```

**Домашнее задание:** отправить себе 3 тестовых заявки с разных устройств
(компьютер, свой телефон, телефон знакомого).

---

### Занятие 6. Запуск в интернет

**Цель:** сайт доступен всему миру по настоящему адресу.
**Результат занятия:** ссылка на ваш сайт, которую можно поставить в соцсети и на визитку.

| Время | Блок |
| --- | --- |
| 0:00–0:30 | Деплой на Vercel: подключаем GitHub-репозиторий, настраиваем переменные |
| 0:30–0:50 | Проверяем боевой сайт: форма, телефонная версия, обе темы |
| 0:50–1:10 | Свой домен: покупка и подключение (или красивый адрес на vercel.app) |
| 1:10–1:30 | Выпускной чек-лист + план развития сайта (см. ниже) |

**Шаги деплоя (повторяем за мастером):**
1. [vercel.com/new](https://vercel.com/new) → вход через GitHub → импорт репозитория.
2. Добавляем переменные: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
3. Deploy → через 2 минуты сайт в интернете.
4. Прописываем адрес сайта в `NEXT_PUBLIC_SITE_URL` и делаем Redeploy.

**Подводный камень:** бесплатный тариф Vercel не подключает репозитории
из GitHub-организаций — репозиторий должен лежать на личном аккаунте.

**Пример промпта:**

```
Давай задеплоим сайт на Vercel. Какие шаги нужно сделать?
Проведи меня по ним и проверь результат.
```

**Выпускной чек-лист:**
- [ ] Сайт открывается по публичной ссылке
- [ ] Заявка с боевого сайта приходит в Telegram
- [ ] На телефоне всё читается, кнопки нажимаются
- [ ] Заголовок и описание корректно видны при отправке ссылки в мессенджер
- [ ] Код сохранён на GitHub, вы умеете делать коммит и пуш

## После выпуска: план развития сайта

Это дорожная карта для самостоятельной работы (или продвинутого потока).
Каждый пункт — одна-две сессии с агентом по той же схеме: промпт → проверка → коммит.

### Ближайшие улучшения (первый месяц)
1. **Настоящие отзывы** — заменить заглушки: имя, фото, ссылка. Два настоящих лучше шести выдуманных.
2. **Секция кейсов «Сделано в мастерской»** — скриншоты работ с коротким описанием результата.
3. **Аналитика** — подключить Яндекс.Метрику или Umami: узнать, откуда приходят и где уходят.
4. **Страница «Спасибо»** после заявки — и постановка цели в аналитике на неё.

### Рост (2–3 месяц)
5. **SEO-статьи в блог** — по одной в неделю: агент помогает с черновиком, вы добавляете экспертизу.
6. **Быстродействие** — прогнать сайт через PageSpeed Insights, попросить агента исправить замечания.
7. **Мини-CRM** — дублировать заявки в Google-таблицу, чтобы ничего не терялось.
8. **Квиз перед формой** — «ответьте на 3 вопроса» повышает конверсию заявки.

### Взрослые фичи (когда появится поток клиентов)
9. **Онлайн-оплата** — приём предоплаты прямо на сайте.
10. **Онлайн-запись** — календарь со свободными слотами вместо переписки.
11. **A/B-тесты заголовков** — какой первый экран приносит больше заявок.
12. **Email-цепочка** — автоматическое письмо-знакомство каждому оставившему заявку.

## Памятка мастера: как ставить задачи агенту

1. **Описывайте бизнес-результат, а не технику.** Не «добавь `div` с классом», а «сделай, чтобы цены было видно сразу с телефона».
2. **Одна задача — один промпт.** Большое задание дробите: сначала структура, потом тексты, потом красота.
3. **Проверяйте глазами после каждого шага.** Браузер — ваш ОТК.
4. **Не нравится — говорите прямо и образно.** «Слишком дёшево выглядит», «хочу теплее», «как в дорогом журнале» — агент понимает такие слова.
5. **Просите объяснений.** «Объясни, что ты сделал, простыми словами» — так вы учитесь у своего же станка.
6. **Сохраняйтесь перед экспериментами.** «Сделай коммит» перед рискованной идеей — и любую неудачу можно откатить.
