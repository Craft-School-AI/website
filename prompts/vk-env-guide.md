# Гайд: как получить значения для `.env` (ВКонтакте)

Чтобы форма отправляла заявки вам во ВКонтакте, нужно заполнить три значения:

```
VK_ACCESS_TOKEN=...   секретный ключ сообщества (даёт право отправлять сообщения)
VK_PEER_ID=...        кому приходит заявка (ваш числовой id ВК)
VK_API_VERSION=5.199  версия API ВК (можно не менять)
```

Ниже — по шагам, где всё это взять. Времени нужно 5–10 минут.

---

## Шаг 0. Нужно сообщество (группа) ВК

Заявки шлёт **сообщество**, а не ваш личный профиль. Если сообщества нет:

1. Откройте [vk.com/groups](https://vk.com/groups) → кнопка **«Создать сообщество»**.
2. Тип — любой (например, «Бизнес»). Название — название вашего дела.
3. Сообщество можно оставить закрытым, оно нужно только как «отправитель».

---

## Шаг 1. Включите сообщения в сообществе

1. Зайдите в сообщество → справа меню **«Управление»**.
2. Раздел **«Сообщения»** → переключатель **«Сообщения сообщества»** → **Включены**.
3. Сохраните.

Без этого сообщество не сможет никому писать.

---

## Шаг 2. Получите `VK_ACCESS_TOKEN` (ключ доступа сообщества)

1. В сообществе: **«Управление»** → **«Настройки»** → вкладка **«Работа с API»**.
2. Подраздел **«Ключи доступа»** → кнопка **«Создать ключ»**.
3. Отметьте галочками права:
   - ✅ **Сообщения сообщества** (обязательно — без него ничего не отправится);
   - ✅ Управление сообществом (можно тоже отметить).
4. Подтвердите (ВК попросит код из SMS/приложения).
5. Появится длинная строка `vk1.a.xxxxxxxx...` — **это и есть `VK_ACCESS_TOKEN`.**

> ⚠️ Это секрет. Никому не показывайте, не выкладывайте в код и в переписку.
> Если засветили — на этой же странице удалите ключ и создайте новый.

---

## Шаг 3. Получите `VK_PEER_ID` (ваш числовой id)

`VK_PEER_ID` — это **кому** приходит заявка. Проще всего слать самому себе, то есть
указать **ваш личный числовой id ВКонтакте**.

### Как узнать свой числовой id

**Способ А (если у профиля нет никнейма).**
Откройте свою страницу. Если адрес выглядит как `vk.com/id123456789` — число
`123456789` и есть ваш id.

**Способ Б (если в адресе никнейм, например `vk.com/ivan`).**
Тогда числовой id так сразу не виден. Возьмите его через сервис-определитель:
откройте [regvk.com/id](https://regvk.com/id/), вставьте ссылку на свой профиль →
получите число. Это ваш `VK_PEER_ID`.

**Способ В (надёжный, через API — у вас уже есть токен).**
Вставьте в адресную строку браузера (подставьте свой ник и токен из шага 2):

```
https://api.vk.com/method/users.get?user_ids=ВАШ_НИК&v=5.199&access_token=ВАШ_ТОКЕН
```

В ответе будет `"id": 123456789` — это `VK_PEER_ID`.
(После проверки закройте вкладку — в адресе виден токен.)

---

## Шаг 4. Разрешите сообществу писать вам (важно!)

ВК не даёт сообществу писать пользователю «в холодную». Чтобы заявки доходили,
**вы должны первым написать своему сообществу**:

1. Откройте страницу сообщества от своего личного профиля.
2. Нажмите **«Написать сообщение»** и отправьте любой текст (например, «тест»).

После этого у сообщества появляется право отвечать вам — и заявки будут приходить.

---

## Шаг 5. `VK_API_VERSION`

Оставьте `5.199` — это актуальная версия API ВК. Менять нужно крайне редко.

---

## Шаг 6. Заполните `.env.local` и проверьте

1. В корне проекта откройте (или попросите агента создать) файл `.env.local`:

   ```
   VK_ACCESS_TOKEN=vk1.a.ваш_ключ_из_шага_2
   VK_PEER_ID=ваш_id_из_шага_3
   VK_API_VERSION=5.199
   ```

2. Перезапустите dev-сервер (переменные окружения читаются при старте).
3. Заполните форму на сайте и отправьте.
4. Проверьте личные сообщения ВК от вашего сообщества — там должна быть заявка.

На проде (Timeweb) эти же три переменные добавляются в настройках окружения
хостинга, **а не в код**.

---

## Частые ошибки и что делать

| Что видно в логах / поведение | Причина | Решение |
|---|---|---|
| `error_code 901` — can't send messages to this user | Вы не написали сообществу первым | Сделайте шаг 4: напишите сообществу с личного профиля |
| `error_code 15` — access denied | У токена нет права «Сообщения сообщества» | Пересоздайте ключ (шаг 2) с нужной галочкой |
| `error_code 5` — auth failed | Неверный или устаревший токен | Скопируйте токен заново, без пробелов |
| `error_code 100` — invalid peer_id | Неверный `VK_PEER_ID` | Проверьте числовой id (шаг 3) |
| «Форма временно недоступна» | Переменные не заданы / сервер не перезапущен | Проверьте `.env.local` и перезапустите сервер |
| Заявка не приходит, ошибок нет | Сообщения в сообществе выключены | Шаг 1: включите сообщения |

---

## Памятка по безопасности

- Токен — как пароль. Не коммитим (`.env*` уже в `.gitignore`), не шлём в чат.
- В браузер токен не попадает: он используется только на сервере (`/api/lead`).
- Публичным (`NEXT_PUBLIC_...`) токен делать нельзя — только внутренние переменные.
- Засветили токен — удалите ключ в сообществе и создайте новый.

---

### Хотите, чтобы заявки видела вся команда?

Вместо личного id можно слать в **беседу**: создайте беседу, добавьте туда коллег,
и используйте `VK_PEER_ID = 2000000000 + номер_беседы`. Номер беседы виден в адресе
`vk.com/im?sel=c<НОМЕР>`. Начните с личного id — это проще, а беседу подключите позже.
