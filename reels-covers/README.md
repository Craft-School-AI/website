# Обложки рилзов Craft School

Единая визуальная система обложек для Instagram Reels Романа и Craft School.
Формат 1080 × 1920 px, читается в сетке профиля.

## Визуальная система

Постоянные элементы на каждой обложке:

- **Фото Романа** во весь кадр, лайфстайл, без обработки внешности.
- **Бренд-плашка** сверху по центру: квадрат со скруглением, градиент
  терракота → янтарь (#BF633A → #D1932F), внутри знак Craft School
  («C» со стрелками кода). Маркер серии, виден даже в мелкой сетке.
- **Заголовок** — 2 короткие строки, Playfair Display Black Italic, капс.
  Первая строка цвета слоновой кости, вторая — фирменный градиент.
  Текст стоит в центральной трети и частично перекрывает человека.

Меняются только фото и текст. Композиция, шрифт, цвета и плашка — нет.

## Как собрать обложки

1. Положить фото (HEIC или JPG) в папку из `photoSourceDir` в `covers.json`
   (по умолчанию `~/Downloads/Reels`).
2. Добавить запись в `covers.json`:
   - `photo` — имя файла без расширения;
   - `l1` — первая строка (белая), `l2` — вторая (фирменный цвет);
   - `pos` — кадрирование фото, CSS object-position (`"50% 25%"`:
     первая цифра — сдвиг по горизонтали, вторая — какая часть фото видна
     по вертикали, меньше — ближе к верху);
   - `ty` — вертикаль текстового блока в процентах высоты (обычно 55–60,
     чтобы текст лёг на грудь/плечи, не закрывая лицо).
3. Запустить:

   ```bash
   node generate.mjs
   ```

   Или только выбранные: `node generate.mjs IMG_2281 IMG_5310`.

Готовые PNG появятся в `out/`. Быстро посмотреть один вариант можно,
открыв `template.html` в браузере с параметрами:
`template.html?photo=<file://путь>&l1=ПЕРВЫЙ%20САЙТ&l2=БЕЗ%20ОПЫТА&pos=50%25%2025%25&ty=56`

## Правила заголовков

- Максимум 2 строки, каждая из 1–2 коротких слов — строка автоматически
  растягивается почти на всю ширину кадра.
- Ключевое слово или интрига — во второй строке (она цветная).
- Без мелких деталей, интерфейсов и лишней графики — обложка должна
  читаться в размере превью сетки.
