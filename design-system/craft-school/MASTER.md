# Craft School — дизайн-система (Master)

Источник правды для визуальных решений на сайте. Страничные исключения кладём
в `design-system/craft-school/pages/<page>.md` — они перекрывают этот файл.

## Продукт и аудитория

- Онлайн-школа: предприниматели без опыта в IT учатся делать сайты с ИИ-агентом.
- Тон: спокойный, конкретный, без пафоса и «нейротекста». Термины: преподаватель,
  ИИ-агент, тарифы Базовый / Стандарт / Индивидуальный. «Цифровая мастерская» — ок.

## Стиль

- База: тёплый минимализм + брутальные акценты («крафтовый брутализм»):
  острые углы (rounded-none), рамка 3px цвета `ink`, плотная смещённая тень
  (`shadow-[Npx_Npx_0_0_rgb(var(--brand-terracotta))]`), «нажатие» на active.
- Иконки — только SVG (lucide-react), эмодзи как иконки не используем.
- Моноширинные ярлыки-подписи: `font-mono text-[10-11px] uppercase tracking-widest`.

## Цвета

Только семантические токены из `app/globals.css` (RGB-триплеты) через Tailwind
(`tailwind.config.js`). Сырые hex в компонентах не пишем (исключения: ivory,
graphite — статичные, не зависят от темы; кислотный `#d4f500` бегущей строки).

- Фоны: `surface` / `surface-soft` / `surface-deep` — чередуем секции для ритма.
- Текст: `ink` / `ink-soft` / `ink-faint`.
- Акценты: `terracotta` (главный), `amber` (всё про ИИ, премиум), `green` (CTA).
- Тёмная тема — класс `.dark`, акценты в ней ярче. Проверять контраст 4.5:1 в обеих.

## Типографика

- Шрифт: Golos Text (`--font-body`), для заголовков — он же жирный.
- Классы: `heading-xl` (герой), `heading-lg` (секции), `heading-md` (карточки);
  базовый текст 16px, line-height 1.5.

## Структура главной (воронка)

1. Hero: оффер + 2 CTA + полоска доверия (аватары учеников → #works).
2. `#audience` «Для кого» — проблема, узнавание себя.
3. Benefits «Чему вы научитесь» — решение.
4. HowItWorks — 4 шага + мини-CTA (программа / записаться).
5. `#works` StudentWorks — доказательство: реальные сайты учеников.
6. `#pricing-teaser` PricingTeaser — ценовой якорь: 3 тарифа без деталей,
   цены зеркалят `lib/tariffs.ts` и страницу /pricing.
7. BlogTeaser — прогрев для тех, кто не готов.
8. `#zayavka` LeadSection — форма заявки.

CTA повторяется по ходу скролла (герой → после шагов → после цены → форма).

## Взаимодействие и доступность

- Тач-цели минимум 44×44px (кнопки, бургер, стрелки слайдеров, ссылки-кнопки).
- Видимый фокус: глобальный `focus-visible` outline терракотой (globals.css).
- Анимации: reveal на скролле 0.7s; всё декоративное отключается через
  `prefers-reduced-motion` (reveal, роботы, листья, бегущая строка).
- Формы: видимые label, ошибки рядом с полем (`role="alert"`), `aria-invalid`.
- Горизонтального скролла страницы нет (`overflow-x: clip` на body).

## Анти-паттерны

- Скругления и мягкие «пузырьковые» карточки — чужой язык.
- Сине-корпоративные палитры — не бренд.
- Текст на фото без скрима; серое-на-сером; hover как единственный способ
  добраться до действия.
